# Лендинг «Быстрый старт с AI»

Проект Валерии — лендинг для её AI-консалтинга для малого бизнеса (ниша:
помощь локальным сервисным бизнесам внедрять AI-инструменты — контент,
общение с клиентами, документы, автоматизация).

## Что это

`index.html` — полностью самостоятельная статическая страница (HTML + CSS +
vanilla JS в одном файле). Никаких фреймворков, сборщиков, npm — просто
открыть в браузере, и всё работает.

Это ручная конверсия дизайна, который изначально был сделан в виде
Claude-артефакта (Design-тип, `.dc.html`-формат на проприетарном рантайме
Claude). Markup, CSS и вся интерактивность (скролл-прогресс, sticky-навигация,
reveal-анимации при скролле, счётчики статистики, 3D-наклон карточек, липкая
заполняющаяся таймлайн-полоса «как это работает», hover-переключение текста в
блоке «боли клиента», автоматически переключающиеся flip-карточки,
FAQ-аккордеон, кнопка «наверх») переписаны вручную на чистый JS без
зависимостей — визуально и функционально страница ведёт себя так же, как
оригинальный артефакт.

## Текущий статус

- Дизайн и анимации готовы и верстались 1:1 с исходным артефактом.
- **Важно:** в 4 местах страницы ссылки на Telegram — заглушки
  `https://t.me/ВАШ_ЮЗЕРНЕЙМ`. Их нужно заменить на реальный юзернейм бота
  (сопутствующий проект — Telegram-бот для приёма заявок, см. ниже), если
  это ещё не сделано.
- Контент (цены, тексты) пока ознакомительный/плейсхолдерный там, где явно
  указано — сверяйся с тем, что говорит Валерия, а не меняй цифры сам.

## Связанный проект

У Валерии есть Telegram-бот для приёма заявок с этого лендинга (`bot.py`,
отдельный репозиторий/папка, задеплоен на Render). Лендинг и бот — одна
воронка: лендинг приводит клиента, дальше он пишет боту. Если Валерия просит
связать их — значит, нужно подставить реальную ссылку на бота в CTA-кнопки.

## Как работать над этим с Валерией

- Она не разработчик, объясняй простыми словами, без лишнего технического
  жаргона.
- Общается по-русски, в неформальном и прямом стиле.
- Предпочитает: сначала обсудить правки, не бросаться сразу писать код —
  собрать список правок, согласовать подход, и только потом менять файл.
- Перед тем как делать изменения, спрашивай, если неоднозначно; если просит
  «сделай сама, как лучше» — выбирай разумное решение самостоятельно и
  объясняй, что выбрала и почему.
